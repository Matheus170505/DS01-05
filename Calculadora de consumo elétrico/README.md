# Primeiro Projeto – Cálculo de consumo eletrodomestico 💻
Este projeto em Python foi criado para praticar o ciclo **Entrada → Processamento →
Saída** e a postagem de programas no Github.
O programa solicita o **Nome da marca do eletrodomestico e o tipo** é requisitado tambem **Seu consumo mensal,horas de uso e o valor da tarifa estadual para consumo**, com os valores corretamente depositado o calculo deve mostrar o **consumo do aparelho mensal em KWh e em R$ Por Kwh**.

# Formulas usadas ⚡💡💲
A formula usada para o consumo mensal foi de **Consumomensal:(Potencia* tempo*30)/1000**
A formula usada para o consumo mensal foi de **Valorgasto=(ConsumoMensal*Custo)**
